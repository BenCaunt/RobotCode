# Robotics telemetry adapters

A trusted server adapter can register a project-scoped stream in [RobotTelemetry](../../apps/server/src/robotics/RobotTelemetry.ts). Give the stream a stable ID, source clock, schema version, and units. Keep the producer token returned by `connect` in the adapter. Reconnecting rotates it, starts a new producer generation, and preserves the stream's query cursor while the server is running. Call `disconnect` on the adapter's shutdown path.

Publish source sequence numbers and timestamps unchanged. When the adapter can map a capture time to the environment's wall clock, include the estimated uncertainty. The service uses capture and receive ages to report freshness. It tracks source sequence gaps and server-side retention loss separately. Send compact numeric observations and versioned evidence references here. Stream images, point clouds, and RRD files over their own data path.

Use `changes` as a coalesced notification. Query recent samples after each wakeup and use the returned cursor to continue after a bounded page. Feed an approved hook from the same notifications and query its inspection state for unavailable, failed, or budget-exhausted evaluations. The hook service records a trigger with a durable event ID and a bounded excerpt from before the event. After the post-event window ends, call `collect` with the event ID. Repeated collection returns the stored result. Use the event ID as an idempotency key if handing evidence off to another trusted service.

Compose the [hook layer](../../apps/server/src/robotics/RobotTelemetryHooks.ts) with the telemetry layer, server secure randomness, and the migrated environment database. Stream buffers and hook registrations are scoped to the running server. The trigger journal survives a restart, and evidence for an unfinished collection may be partial after the stream buffer is lost. Advisory evaluators need a trusted adapter with its own provider authorization. Hook results are evidence for downstream decisions. Physical command authority remains with the robot receiver.
